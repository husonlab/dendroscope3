# Dendroscope 3.9.0

## New features

- Dendroscope releases are now made available via GitHub, for macOS (Apple silicon and Intel), Windows and Linux
  (x86_64 and aarch64). The installers include the Java runtime
- Help -> Check For Updates... looks for a newer release on GitHub and offers to install it
- Help -> Website... and Help -> Reference Manual... open the GitHub pages of the program

## Changed results

- When a tree is saved or exported in Newick, Nexus or Dendroscope format, an edge weight of 1 that was read from the
  input is now written. Earlier versions left it out when no edge with another weight had been read before it, so that
  a tree all of whose edges have weight 1 was written without any weights

## Known issues

- The installers do not contain the example files; they are in the `examples` folder of the repository

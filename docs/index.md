# Dendroscope

Dendroscope is an interactive desktop program for drawing, editing and comparing rooted phylogenetic trees and
networks. It computes consensus trees and rooted phylogenetic networks (cluster networks, galled networks, level-k
networks and hybridization networks) from a set of trees, and draws tanglegrams of two trees or networks.

Open source repository: https://github.com/husonlab/dendroscope3
